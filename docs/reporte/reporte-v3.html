// La tasa es un porcentaje unico sobre el total prestado: un credito de
// 10.000 al 45% se devuelve siempre por 14.500, sea en 6 cuotas o en 24.
// Strategy: estrategia concreta
public class InteresSimple implements CalculoDeCuota {

    private static final BigDecimal CIEN = new BigDecimal("100");

    private BigDecimal totalADevolver(BigDecimal capital, BigDecimal tasaInteres) {
        BigDecimal coeficiente = BigDecimal.ONE.add(tasaInteres.divide(CIEN, 4, RoundingMode.HALF_UP));
        return capital.multiply(coeficiente).setScale(2, RoundingMode.HALF_UP);
    }

    @Override
    public BigDecimal importeCuota(BigDecimal capital, BigDecimal tasaInteres, int cantidadCuotas) {
        return totalADevolver(capital, tasaInteres)
            .divide(BigDecimal.valueOf(cantidadCuotas), 2, RoundingMode.HALF_UP);
    }
}

// La tasa es mensual sobre el saldo: cuota fija = C * i / (1 - (1 + i)^-n).
// Con tasa 0 la cuota es el capital dividido en partes iguales.
// Strategy: estrategia concreta
public class SistemaFrances implements CalculoDeCuota {

    private static final MathContext PRECISION = MathContext.DECIMAL64;

    @Override
    public BigDecimal importeCuota(BigDecimal capital, BigDecimal tasaInteres, int cantidadCuotas) {
        BigDecimal i = tasaInteres.divide(new BigDecimal("100"), PRECISION);
        if (i.signum() == 0) {
            return capital.divide(BigDecimal.valueOf(cantidadCuotas), 2, RoundingMode.HALF_UP);
        }
        BigDecimal descuento = BigDecimal.ONE.subtract(
            BigDecimal.ONE.divide(BigDecimal.ONE.add(i).pow(cantidadCuotas, PRECISION), PRECISION));
        return capital.multiply(i).divide(descuento, 2, RoundingMode.HALF_UP);
    }
}

Los dos planes, en criollo

Cuota = capital (lo prestado) + interés (lo que cobra el que presta). Los sistemas difieren en sobre qué se calcula el interés.

  • Interés simple: una vez, sobre todo lo prestado, repartido en partes iguales. “30 %” = 30 % del total.
  • Sistema francés (el de los bancos): cuota fija, interés mensual sobre el saldo. “5 %” = 5 % por mes. Fórmula: cuota = C·i / (1 − (1+i)^−n).

Ejemplo: $12.000 en 6 cuotas.

Interés simple, tasa 30 % total

Total = 12.000 × 1,30 = 15.600. Cuota = 15.600 / 6 = 2.600 todos los meses: 2.000 de capital y 600 de interés. Interés total: 3.600.

Sistema francés, tasa 5 % mensual

Cuota fija = 2.364,21. Mes 1: interés 5 % de 12.000 = 600. Mes 6: interés 5 % de lo poco que queda = 112,58. Total = 14.185,26; interés total: 2.185,26.

Por qué el francés: la segunda ConcreteStrategy

  • “Misma acción, distintos algoritmos” (clase 9): calcular la cuota, dos fórmulas reales.
  • Revierte el descarte del 15/09 (V2). En V2 el objetivo era la convención interfaz + clase, y un solo algoritmo alcanzaba. En V3 el tema es Strategy: necesita dos algoritmos que de verdad varíen.

Quién elige y por qué no hay setEstrategia

  • Elige quien otorga, en ejecución: <select> → CreditoRequest.tipoPlan → TipoPlan.calculo().
  • Sin setEstrategia: el plan es parte del contrato. Cambiarlo alteraría cuotas ya emitidas.
  • Enum y no campo de interfaz: JPA persiste un @Enumerated, no una interfaz. TipoPlan es el registro de estrategias.

Límites conocidos

  • Un plan nuevo toca el enum (registro): OCP se cumple para Credito y las estrategias.
  • La cuota no separa capital e interés; el “interés simple” es un recargo plano (P-M9).

// Adapter: implementa TokenService (Target) y delega en JwtParser/SecretKey de jjwt (Adaptee, por composicion)
@Component
public class JwtUtil implements TokenService {

    private final SecretKey key;
    private final JwtParser parser;
    private final long expirationMs;

    public JwtUtil(@Value("${jwt.secret}") String secret,
                   @Value("${jwt.expiration-ms}") long expirationMs) {
        this.key = Keys.hmacShaKeyFor(secret.getBytes());
        this.parser = Jwts.parser().verifyWith(key).build();
        this.expirationMs = expirationMs;
    }

    @Override
    public String generarToken(String username) {
        return Jwts.builder()
            .subject(username)
            .issuedAt(new Date())
            .expiration(new Date(System.currentTimeMillis() + expirationMs))
            .signWith(key)
            .compact();
    }

    @Override
    public Optional<String> extraerUsername(String token) {
        try {
            return Optional.ofNullable(extraerClaim(token, Claims::getSubject));
        } catch (JwtException | IllegalArgumentException e) {
            return Optional.empty();
        }
    }

    @Override
    public boolean esValido(String token, String username) {
        return extraerUsername(token).filter(username::equals).isPresent();
    }

    private <T> T extraerClaim(String token, Function<Claims, T> resolver) {
        Claims claims = parser
            .parseSignedClaims(token)
            .getPayload();
        return resolver.apply(claims);
    }
}
