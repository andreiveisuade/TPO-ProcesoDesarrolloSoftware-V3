# M6 — Cuota.estaVencida()

## Patrón

Information Expert (GRASP): la cuota tiene `fechaVencimiento` y sabe si está pagada, entonces ella responde si está vencida.

## Problema

`fechaVencimiento` se guardaba y nadie la usaba. No existía el concepto de mora; la vista solo distinguía Pagada / Pendiente.

```java
// v2: model/Cuota.java
public boolean estaPagada() {
    return cobranzas.stream().anyMatch(cobranza -> !cobranza.isAnulada());
}
// v2: CuotaResponse.desde(...) solo exponía pagada
```

## Solución

```java
// model/Cuota.java
public boolean estaVencida() {
    return !estaPagada() && fechaVencimiento.isBefore(LocalDate.now());
}
```

`ICuota` declara `estaVencida()`, `CuotaResponse` suma el campo `vencida` y `Creditos.jsx` muestra Pagada / Vencida / Pendiente.

## Por qué

Cierra el hueco H3 (A-05 de V0): saber qué cuotas están en mora es la pregunta central de un sistema de cobranzas. La regla vive en la entidad que tiene los datos, no en el service ni en la vista.

## Consecuencias

Gana: la mora es consultable desde el modelo y reutilizable (dashboard, reportes). Cuesta: `estaVencida()` depende del reloj del sistema (`LocalDate.now()`), lo que dificulta testearla sin inyectar un `Clock`.
